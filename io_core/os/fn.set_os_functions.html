pub fn set_os_functions(f: &'static OsFunctions)
Available on target_has_atomic=ptr only.
Expand description

Sets the functions used by this crate to have expandable OS handling.

This should be called before any I/O interaction to be properly used by this crate if you are in a system we have no support by default.

This function allows you to have robust I/O Error support even on your custom system or niche OS.
